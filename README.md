# Sprint 7 – Python Programming

## IT Academy Barcelona | Data Analytics Bootcamp

This repository contains the exercises completed during Sprint 7 of the Data Analytics specialization at IT Academy Barcelona.

The sprint focuses on Python programming fundamentals, modular programming, data structures, functions, loops, conditional statements, and data processing.

## Exercises

### Level 1
- **Exercise 1 – Personnel Selection:** Candidate registration, input validation, score calculation, classification, and ranking.
- **Exercise 2 – Marketing Data Analysis:** Processing customer data and displaying analytical results.

### Level 2
- **Exercise 1 – Patient Data Analysis:** Processing patient information, risk classification, and sorting results.
- **Exercise 2 – Insurance Data Analysis:** Processing insurance customer data and analyzing fraud-related information.

### Level 3
- **Exercise 1 – Password Generator:** Generating configurable passwords using Python and NumPy.
- **Exercise 2 – Sports Data Analysis:** Processing football match records, calculating team statistics, and generating league standings using Pandas.

## Technologies
- Python
- NumPy
- Pandas
- Google Colab

## Project Structure

The exercises are organized in a Jupyter Notebook (`.ipynb`) containing step-by-step algorithms, Python functions, and test results.
